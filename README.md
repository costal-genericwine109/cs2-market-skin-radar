## 📖 How to Use the Tool

### The Main Dashboard
Once you open `index.html`, you will see a clean interface with several sections:

- **Search Bar** – Type the name of any CS2 skin to filter results.
- **Price Comparison Table** – The core of the tool. This table shows each Skinport listing alongside its Steam Community Market price. The difference (discount) is highlighted.
- **Real-Time Update Indicator** – A small status icon shows if data is currently loading. Data updates automatically every few minutes.
- **Sorting Options** – Click column headers like "Discount %" to sort from highest to lowest discount. This helps you quickly the best deals.

### Understanding the Number

- **Skinport Price** – What sellers are asking on Skinport.
- **Steam Market Price** – The current average sale price on Steam (this includes market fees).
- **Discount %** – The percentage difference between the two prices. For example, 20% means the Skinport listing is 20% cheaper than Steam.
- **Estimated Profit** – Approximate profit you could make if you bought on Skinport and sold on Steam (after fees).

### Getting the Most Out of It
- Refresh manually if prices seem outdated by clicking the refresh button in the toolbar.
- Use the search bar to find specific skins like "AK-47 | Redline".
- Sort by highest discount first to see the most profitable opportunities.
